A single Python program (standard library only, no network, fully deterministic) that draws a black-and-white newspaper front page — "The Daily Signal" — summing up the world news of Saturday 21 November 2026 in one 1024×1024 PNG. The lead story covers the Russian missiles and suspected drone that came down in Poland during the massive overnight strike on Ukraine; inside are the ICJ genocide verdict on Myanmar, the Trump–Xi–Putin trilateral summit in Shenzhen, Wall Street's 3.7% slump with a hand-drawn falling chart, the UK–EU deals signed in Brussels, and a World Briefs column on Riyadh, a pancreatic-cancer pill breakthrough, and the stalled climate talks. Every letter is stamped from a built-in 5×7 pixel font and the PNG is encoded by hand with zlib, so two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
